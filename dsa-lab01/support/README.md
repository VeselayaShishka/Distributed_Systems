# Support: choose the page you need

Keep the [activity guide](../DSA-LAB-01-docker-rest.pdf) as your route through the milestone. These pages help at a particular obstacle; reading them all first is unnecessary.

- [Setup](setup.md): Python, virtual environment, two terminals, Windows commands and local port fallback.
- [HTTP contract](contract.md): required behavior, story statuses and file-based request examples.
- [Docker](docker.md): build/run, inspection, stop/start, changed publication and cleanup.
- [Troubleshooting](troubleshooting.md): match your observed symptom to a useful check.

Return to your checkpoint after resolving the obstacle. Write the result and your explanation in [observations](../docs/observations.md).
